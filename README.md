### Project 1: Expressions & Alerts
Practice with JavaScript expressions, string concatenation, and the `alert()` function to display output to the user.

### Project 2: Functions
Refactored earlier code into reusable functions, triggered by a button click, to practice organizing logic with JavaScript functions.

### Project 3: Math Operators
Explores JavaScript's arithmetic operators, with a separate function for each operator (addition, subtraction, multiplication, division).

### Project 4: Dictionaries
Practice working with JavaScript objects (dictionaries), including adding, reading, and removing properties with the `delete` operator.

### Project 5: Comparisons & Type Coercion
Demonstrates the `typeof` operator, type coercion, and comparison/logical operators (`==`, `===`, `>`, `<`, `&&`, `||`, `!`), with results displayed using `document.write()`.

### Project 6: Ternary Operators & Constructors
Uses a ternary operator to check if a number is even or odd, and a constructor function (using `new` and `this`) to create a `Person` object with a nested greeting function.

### Project 7: Scope, Time & Function
Covers local vs. global variable scope, a function with an if statement, a debugged function (fixed using `console.log()` in Chrome Dev Tools), and a `Time_function()` that displays and updates the current time every second.

### Project 8: String Methods
Demonstrates JavaScript string methods `concat()`, `slice()`, `toString()`, and `toPrecision()`, each with its own function and button to display the result.

### Project 9: Countdown & Slideshow
Includes a `countdown()` function that counts down from a set number of seconds, and a basic image/color slideshow built with HTML, CSS, and JavaScript that automatically cycles through slides.

### Project 10: Loops & Arrays
Demonstrates a `while` loop, a `for` loop, a function that loops through an array, and an object created using the `let` keyword.

### Tic Tac Toe
A fully functional two-player Tic Tac Toe game built with HTML, CSS, and JavaScript, including win detection for all rows, columns, and diagonals, and a reset button.

### Calculator
A fully functional calculator app supporting addition, subtraction, multiplication, and division, with clear and delete buttons and error handling for invalid expressions.

### Pizza Menu
A pizza ordering app where users choose quantities for different pizzas from a menu, then calculate and display an itemized order summary with the total price.
